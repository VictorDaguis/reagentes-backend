# 🧪 Laborsolo – Controle de Estoque de Reagentes

API REST desenvolvida com Node.js, Express, Sequelize e SQLite para controle de estoque laboratorial.

## 📋 Funcionalidades
- Autenticação JWT
- CRUD de Usuários
- CRUD de Reagentes
- CRUD de Movimentações de Estoque (entrada/saída)

## 🛠️ Tecnologias
- Node.js + Express
- Sequelize ORM + SQLite
- JSON Web Token (JWT)
- Bcrypt

## ⚙️ Como rodar
1. Clone o repositório
2. Instale as dependências com `npm install`
3. Crie um arquivo `.env` com as variáveis:
4. 
JWT_SECRET=laborsolo_secret_2026
PORT=3000

4. Execute `npm run dev`
5. Acesse `http://localhost:3000/api`
